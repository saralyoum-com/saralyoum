# Wikipedia Citation Opportunities

Wikipedia is DA 100 — the highest authority backlink available. Even one Wikipedia citation can be worth 100+ regular backlinks for SEO purposes.

## Strategy

1. **Don't be salesy.** Wikipedia editors will remove obvious promotion.
2. **Cite as a source**, not promote your site.
3. **Add factual information** with sardhahab.com as the source.
4. **Edit existing articles** — don't create new ones about yourself.

## Account Setup

1. Create a Wikipedia account: https://en.wikipedia.org/wiki/Special:CreateAccount
2. Make 10 unrelated edits first to establish editor credibility
3. Add a user page with disclosure: "I founded sardhahab.com — I disclose this when editing related articles"

This is REQUIRED under Wikipedia's Conflict of Interest policy.

## Best Practices

### DO
✅ Disclose conflict of interest on your user page
✅ Add genuinely informative content, not promotional
✅ Cite sardhahab.com as a SOURCE, not a recommendation
✅ Make edits that improve the article
✅ Follow Wikipedia's manual of style
✅ Wait 24-48 hours between major edits
✅ Use the Talk page if uncertain

### DON'T
❌ Edit articles to promote your site
❌ Add the same citation to multiple articles in one day
❌ Use peacock language ("best", "leading", "premier")
❌ Edit-war if your changes get reverted
❌ Create a Wikipedia article about sardhahab.com (not notable enough yet)
❌ Use multiple accounts (sockpuppeting — instant ban)

## What Triggers Removal

Wikipedia editors will remove your citation if:

1. **It's not authoritative** — They might see sardhahab.com as too new
2. **It's redundant** — If another better source covers it
3. **It's promotional** — Wording too sales-y
4. **It's not the original source** — Original research/data sources preferred

To minimize removal:
- Cite specific factual claims (prices, dates, statistics)
- Frame as data source, not opinion source
- Improve the surrounding text quality
